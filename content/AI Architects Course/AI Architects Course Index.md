## 课程概述

AI Architects 是一门系统化课程，旨在帮助你从"能用 AI 搭东西的人"蜕变为"能设计生产级 AI 系统的人"。课程围绕 SuperMind 项目展开，通过 ABA Prime 路径（Phase A 核心解密 → Phase B 应用与创新 → Phase C 进阶架构）带你从 Builder 进化为 Architect。

核心方法论是"管理-创造工作流"：把 AI 当作直接下属，通过设定 OKR、撰写任务简报、进行绩效复盘来驾驭 AI。三大超能力支柱：无摩擦交互、情境智能、主动智能。

## 核心洞察

1. **Builder vs Architect**：Builder 注重解决当下问题，Architect 注重设计系统未来。升级的不是代码速度，而是 Mindset。
2. **四大工程瓶颈**：Prompt 脆弱性、上下文高墙、单次调用局限、单一模型孤岛——需要系统化方案而非更多 Prompt 技巧。
3. **AI 友好性优于性能**：FastAPI 的 openapi.json 让 AI 直接读懂接口，Pydantic 类型注解创造"提早失败"反馈回路。
4. **Agentic Loop 是 Agent 的本质**：LLM 生成 Tool Call 请求，代码执行后喂回结果，LLM 再决策——这个循环定义了 Agent。
5. **管理-创造工作流**：把 AI 当下属，三步循环——定义 OKR、撰写任务简报、进行绩效复盘。这是可复用的元技能。
6. **静态 RAG vs Agentic RAG**：静态 RAG 是线性流水线，Agentic RAG 是动态智能循环，检索器只是 Agent 工具箱里的一件工具。
7. **两阶段扫描**：主动智能的核心架构——先广度扫描识别信号，再深度分析交叉验证，用 background.md 提供战略上下文。
8. **Context Engineering**：让不可见的变得可见。从 print 日志侦探到 Context Debugger，观察上下文轨迹是调试 Agent 的根本原则。
9. **多模型编排两种范式**：Personality-Based Orchestration（按模型特长分工）与 Context Window Separation（隔离上下文噪声）。
10. **为失败而架构**：生产级系统必须有回退机制，高级工作流失败时优雅降级到简单模式。
