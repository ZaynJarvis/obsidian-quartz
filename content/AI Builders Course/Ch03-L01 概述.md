# 概述

## 我的理解

本模块是课程的实战环节，通过五个真实项目帮助学员打通理论与实践的鸿沟。项目的核心主题是借助浏览器和 Web 技术，将图形用户界面（GUI）与应用程序接口（API）连接起来，直接呼应模块一的技术洞察。每个项目被设计为可在十分钟内借助 AI 辅助完成，兼顾独立性与挑战性，学员可按兴趣自由选择。本模块强调「动手即学」——只有亲身经历网页抓取、脚本编写和 GUI 自动化，才能真正理解构建者心态的具体含义。

## 原文

Lesson 17 of 68
概述 / Overview

在前面的模块中，我们探讨了 GenAI 带来的变革性力量，并深入了解了其内部工作原理与最佳实践。我们看到 GenAI 如何自动化各类任务、提升生产力，并把我们的注意力从琐碎事务转向具有战略意义、高价值产出的工作。在此基础上，本模块提供一系列动手项目，帮助你打通理论与实践之间的鸿沟。这些项目聚焦于将图形用户界面（GUI）与应用程序接口（API）连接起来，并着重展示浏览器和 Web 技术如何在这种集成中扮演强大工具的角色。

这些项目乍看之下可能颇具挑战性，但只要心态得当、工具用对，它们其实是可以轻松完成的。通过有效借助 AI 辅助、并使用恰当的提示词，你应当能够在十分钟内完成每一个项目。如果你发现自己花费的时间明显更长，完全可以暂停下来，借助答疑时间或回放课程获得进一步的指导。

你可以根据兴趣自由选择任何项目。每个项目都可独立完成，但全部参与将带来最完整的学习体验。在本模块结束时，你将对如何在实际场景中运用 GenAI 有更深入的理解，尤其是在借助 Web 技术连接 GUI 与 API 方面。

关键洞察

实践是巩固理论的最佳方式。通过完成这些项目，你将亲身体验如何利用 GenAI 自动化任务、与 Web 界面交互，并克服数字环境中常见的各种挑战。

English Original

In the previous modules, we explored the transformative power of GenAI and dived into its internal workings and best practices. We learned how GenAI can automate tasks, enhance productivity, and shift our focus from mundane activities to strategic, high-impact endeavors. Building on that foundation, this module offers hands-on projects designed to bridge the gap between theory and practice. These projects focus on connecting Graphical User Interfaces (GUIs) with Application Programming Interfaces (APIs), emphasizing how browsers and web technologies serve as powerful tools in this integration.

While the projects may initially appear challenging, they are crafted to be approachable with the right mindset and tools. By effectively using AI assistance and applying proper prompts, you should be able to complete each project within ten minutes. If you find yourself spending more time, it's perfectly acceptable to pause and seek additional guidance through our office hours or recorded sessions.

Feel free to select any project that piques your interest. Each project stands independently, but engaging with all of them will provide the most comprehensive learning experience. By the end of this module, you will have a deeper understanding of how to leverage GenAI in practical scenarios, particularly in connecting GUIs and APIs using web technologies.

Key Insight

Practical application reinforces theoretical knowledge. By working through these projects, you will gain firsthand experience in using GenAI to automate tasks, interact with web interfaces, and overcome common challenges in the digital environment.
